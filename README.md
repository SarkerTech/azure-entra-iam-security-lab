# Azure Entra ID IAM Security Lab

## Overview

This project is a hands-on cloud security lab focused on Identity and Access Management (IAM) in Microsoft Azure and Microsoft Entra ID.

The lab will explore how identities, groups, roles, and permissions can be configured to control access to Azure resources while following the principle of least privilege.

> **Status:** Lab in progress.

## Objective

The objectives of this lab are to:

- Understand Microsoft Entra ID identity management
- Create and manage test users and groups
- Understand Azure Role-Based Access Control (RBAC)
- Apply least-privilege access
- Compare different Azure roles and permissions
- Test authorized and unauthorized access
- Review security and activity logs
- Document security findings and remediation
